# 📚 课程登记（轻量手机端）

记录孩子课外辅导班上课次数的轻量应用。**无后端、无需安装、占用资源极少**，数据全部存在手机浏览器本地（localStorage）。每台手机 / 浏览器数据各自独立，互不影响。

## 功能

1. **登记次数**：每门课一个「✓ 上课 +1」大按钮，点一下累加 1 次；支持撤销、查看历史、按条删除。
2. **分课程记录**：不同课程独立计数，各自显示「本周 / 今日 / 累计」。
3. **定时提醒**：给每门课设置「每周上课日 + 开始/结束时间」，默认结束 30 分钟后提醒登记（可自定义 0–360 分钟）。
4. **手机端友好**：单文件 HTML，加载极快；可「添加到主屏幕」当 App 用，离线也能打开。

## 部署（多人访问）

### 方式一：本地局域网（最快，无需公网）

电脑上装好 [Node.js](https://nodejs.org/)，在本目录运行：

```bash
node server.js
```

终端会打印「手机访问」地址（形如 `http://192.168.x.x:8080`）。让手机与电脑连接**同一个 WiFi**，手机浏览器打开该地址即可。多人可同时访问，各自数据存在各自手机浏览器里。

### 方式二：GitHub Pages（公网可访问，能当 App 用）

1. 把本仓库推送到 GitHub（`main` 分支）。
2. 在仓库 **Settings → Pages** 中，把 **Source** 选为 **GitHub Actions**（只需设置一次）。
3. 之后每次 `push` 到 `main`，`.github/workflows/pages.yml` 会自动发布；稍候在 **Settings → Pages** 页面即可看到公网地址（形如 `https://<用户名>.github.io/<仓库名>/`）。

手机浏览器打开后，用 **「添加到主屏幕」**：
- **iPhone**：Safari → 分享按钮 → 「添加到主屏幕」
- **Android**：Chrome → 菜单 → 「安装应用」/「添加到主屏幕」

安装后即可全屏打开、离线使用，图标也换成了应用图标。

### 方式三：直接打开（单机最快）

把整个 `attendance-app` 文件夹传到手机上（微信/QQ 发送或数据线拷贝），用浏览器打开 `index.html` 即可。

## 关于「结束 30 分钟后提醒」的说明

网页应用的提醒能力受浏览器限制，请了解实际效果：

| 状态 | 提醒方式 |
|------|----------|
| 应用**正打开着** | ✅ 顶部横幅 + 系统通知 + 震动，每分钟自动检查 |
| 已安装 PWA、在后台 | ⚠️ 多数 Android Chrome 能收到通知，iOS 仅偶尔 |
| 完全关闭应用 | ❌ 网页无法在后台定时推送（需要服务器推送） |

**最可靠的做法**：上课结束 30 分钟后，只要打开一下这个页面（或锁屏下拉通知栏），就会立刻看到该登记的提醒。

> 若需要「应用关闭也能准时推送」，需要增加一个轻量服务器做 Web Push。可后续补充。

## 数据说明

- 数据存在浏览器本地 `localStorage`，清除浏览器数据会丢失，请定期留意。
- 换设备/换浏览器数据不互通（无账号同步）。
